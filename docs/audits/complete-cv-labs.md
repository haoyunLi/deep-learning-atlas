# CV and sequence computed-lab audit

Date: 2026-10-29. Scope: all 54 IDs assigned to the CV/sequence authoring group. Entry point: `src/data/completeLabs/cv.ts`. No global registry, UI or other authors' course files are changed by this group.

## Completion and validation

All 54 courses now have a parameter-controlled calculation with four progressive stages, intermediate numerical values, and bars, lines or matrices. Every lab includes two use cases, two tuning notes, two symptom/check/action troubleshooting paths, a stated simplification boundary and a primary source. Each lab uses one numeric control to isolate the demonstrated mechanism; it is explicitly described when the control changes input, an architecture choice, or an illustrative model coefficient rather than a production inference setting.

`node scripts/validate-complete-cv.mjs` passes: **54 courses, 916 slider states, 98 independent expected-value assertions**. The expected-value fixtures were written from hand calculations and closed-form derivations; they are not generated by the lab calculators. Additional checks cover probability conservation, geometric identities, discrete mask behavior, tensor-budget scaling, recurrence/convolution agreement and limiting cases. The script also checks every advertised slider tick for four stages, finite outcomes/charts, valid matrix dimensions, unique labels and changing outcomes. The expected ID set is explicit and permanent, with no `/tmp` dependency.

Important independent checks include:

- RANSAC's required iteration count is the smallest integer reaching the requested success probability under the stated independent/nondegenerate assumptions.
- TCN receptive support is enumerated as reachable lags through two convolutions per block, separately from the closed-form formula in the lab.
- CTC enumerates all four two-frame paths; their probabilities sum to one, and target probability equals the complement of the all-blank path.
- Speculative Decoding's accepted mass plus rejection residual recovers the target distribution for every control tick, including the `p=q` unused-residual branch.
- RWKV direct history weights agree with numerator/denominator recurrences. Scalar SSM recurrence agrees with impulse superposition. Mamba's explicitly stated ZOH toy agrees with an independently expanded expression.
- BPE merges preserve the original string and total character count; RoPE preserves vector norm; causal attention assigns exactly zero weight to the future token.
- Dice/IoU identity, identical-box GIoU loss, stereo depth/disparity product, 3D patch volume scaling, bilinear linearity, GQA groups/cache tradeoff and Particle Filter symmetry/ESS bounds are checked.

## Source verification

Each course keeps a primary source linked inside its lab. The following mechanism details were additionally checked against primary papers or official source/documentation during authoring:

- [PyTorch Conv2d](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv2d.html): dilation, groups and convolution shape conventions. [Computing Receptive Fields](https://distill.pub/2019/computing-receptive-fields/): theoretical receptive field recurrences and limitations.
- [Swin Transformer](https://arxiv.org/abs/2103.14030) and [MobileNetV2](https://arxiv.org/abs/1801.04381): local windows and inverted bottleneck/depthwise mechanisms. The labs count selected tensor/operation budgets rather than model accuracy.
- [GQA](https://arxiv.org/abs/2305.13245) and [Hugging Face cache explanation](https://huggingface.co/docs/transformers/main/en/cache_explanation): query grouping and growing KV state. Logical storage is distinguished from total device memory and latency.
- [OpenCV stereo geometry](https://docs.opencv.org/4.x/dd/d53/tutorial_py_depthmap.html): rectified depth `Z=fB/disparity`.
- [TCN](https://arxiv.org/abs/1803.01271): causal dilated convolution; the lab explicitly fixes two kernel-3 convolutions per block.
- [SGNS paper](https://arxiv.org/abs/1310.4546): the source for the new word2vec lab was made more specific than the original introductory word-vector paper.
- [T5 paper, Figure 2 and Section 3.1.4](https://www.jmlr.org/papers/volume21/20-074/20-074.pdf): consecutive corrupted tokens share a sentinel and the paper describes a final sentinel. The toy explicitly adds EOS and warns that preprocessing variants differ.
- [Mamba](https://arxiv.org/abs/2312.00752) and [RWKV Appendix D](https://arxiv.org/html/2305.13048v2): selective state updates, time decay, time-first term and recurrent numerator/denominator state. The Mamba lab is an explicit scalar ZOH illustration, not a claim of exact full-block replication.
- [Original CTC paper, Section 3.1](https://www.cs.toronto.edu/~graves/icml_2006.pdf): sequence probability sums over all paths mapped to the target. The attempted PyTorch 2.15 CTC page was unavailable to the browser tool, so the original paper was used directly.
- [Official Whisper audio frontend](https://github.com/openai/whisper/blob/main/whisper/audio.py): squared magnitudes, Mel projection, `log10` floor, global dynamic-range floor and affine normalization. The lab uses a disclosed two-band synthetic filterbank, not the production filterbank.
- [Speculative Decoding, Section 2.3 and Appendix A](https://proceedings.mlr.press/v202/leviathan23a/leviathan23a.pdf): conditional acceptance `min(1,p/q)` and normalized positive residual. Same distribution is distinguished from identical strings under the same seed.

## Scientific and interaction boundaries

No lab runs a trained checkpoint or presents synthetic curves as observed model performance. Architecture labs report scoped channels, receptive fields, score entries, parameters or MACs. They do not infer accuracy, full memory usage or device latency. The only 32-point plot is a complete 32-frame sampling timeline; all other visual fixtures are small and representative.

SAM is prompt-consistency filtering over three disclosed masks, not SAM inference. Mask R-CNN is one bilinear sample, not all RoIAlign bins. UNet++ demonstrates deep supervision weights, not a full nested decoder. Proposal recall is a diagnostic for fixed proposals, explicitly **not a strict upper bound** on final detector recall because box regression can change overlap.

ICL is a fixed attention-based context reader, explicitly an analogy, not a full account of ICL or an LLM accuracy estimate. CoT uses independently checkable arithmetic decomposition; it does not display or claim to infer a model's hidden reasoning. Particle Filter uses a fixed resampling offset for reproducibility, not a random Monte Carlo run. T5 uses separated masked spans with a fixed total of six masked tokens; contiguous tokens are not incorrectly represented as several independent spans.

The final full-site build, browser playback/reference-comparison checks and deployment are owned by the parent task. Local course calculations are independently checked here; no deployment is claimed in this audit.
